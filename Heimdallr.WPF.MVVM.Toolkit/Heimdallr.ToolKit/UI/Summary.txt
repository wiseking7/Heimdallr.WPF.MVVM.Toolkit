● DefaultStyleKeyProperty 
  DefaultStyleKeyProperty 는 WPF에서 커스터마이즈된 스타일을 정의하고 사용할 때 
  중요한 역할을 하는 DependencyProperty입니다. 
  이를 이해하려면, WPF의 스타일 시스템과 컨트롤의 템플릿 개념에 대한 기본적인 이해가 필요합니다  

  1. DefaultStyleKey란?
     WPF에서 DefaultStyleKey 는 컨트롤의 기본 스타일을 정의하는 키입니다. 
     WPF의 스타일 시스템은 특정 컨트롤 유형에 대한 기본 스타일을 **리소스 딕셔너리(ResourceDictionary)**에서 찾습니다. 
     이 스타일은 해당 컨트롤에 대한 기본적인 모양과 동작을 정의합니다.

     DefaultStyleKey는 이 스타일을 찾는 데 사용되는 식별자 역할을 하며, 보통 Custom Control을 만들 때 이 프로퍼티를 설정합니다. 
     이 키를 통해 WPF는 해당 컨트롤의 기본 스타일을 자동으로 로드합니다

  2. DefaultStyleKeyProperty의 역할
     DefaultStyleKeyProperty는 DefaultStyleKey라는 DependencyProperty의 정적 필드로, WPF 컨트롤에 기본 스타일을 할당하는 키를 제공합니다. 이 키를 설정하여 컨트롤의 스타일을 커스터마이즈할 수 있습니다.

     간단히 말해, DefaultStyleKeyProperty는 컨트롤 클래스에 해당 스타일을 정의할 때 사용할 수 있는 특수한 속성입니다. 
     컨트롤이 Custom Control인 경우, 이 속성을 통해 리소스 딕셔너리에서 스타일을 찾을 수 있도록 합니다.
  
  3. 기본 스타일을 찾는 과정
     WPF는 리소스 시스템을 사용하여 스타일을 찾습니다. 기본적으로 WPF는 다음과 같은 경로를 따라 스타일을 찾습니다:

     컨트롤의 DefaultStyleKey에 지정된 값을 사용하여 스타일을 찾습니다.

     스타일은 Themes/Generic.xaml 파일이나 사용자 정의 스타일이 포함된 리소스 딕셔너리에서 검색됩니다.

     만약 스타일을 찾을 수 없으면, 기본 스타일이 적용됩니다.

  4. DefaultStyleKey를 설정하는 이유
     DefaultStyleKey는 주로 Custom Control을 정의할 때 사용됩니다. 
     기본 컨트롤(Button, TextBox 등)은 이미 기본 스타일이 제공되지만, 
     Custom Control을 만들 때는 디폴트 스타일을 별도로 정의해야 합니다.

     Custom Control을 만들 때 DefaultStyleKey를 설정하는 이유는:

     자동 스타일 적용: DefaultStyleKey를 사용하여 해당 컨트롤에 대한 기본 스타일을 자동으로 적용할 수 있습니다.

     리소스 관리: 스타일을 외부 리소스 파일에서 쉽게 관리하고 변경할 수 있습니다.

  5. DefaultStyleKeyProperty 사용 예시
     1. Custom Control 생성
        우리는 먼저 Custom Control을 만들고, 그에 대해 기본 스타일을 설정할 것입니다. 
        이를 통해 DefaultStyleKey의 사용법을 이해할 수 있습니다.

// CustomControl1.cs
public class CustomControl1 : Control
{
    static CustomControl1()
    {
        DefaultStyleKeyProperty.OverrideMetadata(
            typeof(CustomControl1),
            new FrameworkPropertyMetadata(typeof(CustomControl1))
        );
    }
}

     여기서 중요한 부분은 DefaultStyleKeyProperty.OverrideMetadata 메서드를 사용하는 것입니다. 
     이를 통해 Custom Control에 대해 DefaultStyleKey를 설정하고, 해당 스타일을 정의할 수 있습니다.

     DefaultStyleKeyProperty.OverrideMetadata 메서드는 컨트롤 클래스에 대한 스타일을 기본 스타일 리소스와 연결합니다.

     FrameworkPropertyMetadata는 이 프로퍼티가 Custom Control의 기본 스타일을 설정하는 데 사용된다는 것을 알려줍니다.

     2. 스타일 정의 (Generic.xaml)
        Custom Control에 대한 스타일은 리소스 딕셔너리에서 정의됩니다. 
        보통 Themes/Generic.xaml 파일에 정의하며, 
        이 파일은 애플리케이션에서 사용되는 모든 Custom Control에 대한 스타일을 포함합니다.

<!-- Themes/Generic.xaml -->
<ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
                    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">
    <Style TargetType="local:CustomControl1">
        <Setter Property="Background" Value="LightBlue"/>
        <Setter Property="Height" Value="100"/>
        <Setter Property="Width" Value="200"/>
        <Setter Property="Template">
            <Setter.Value>
                <ControlTemplate TargetType="local:CustomControl1">
                    <Border Background="{TemplateBinding Background}">
                        <TextBlock Text="This is a custom control" HorizontalAlignment="Center" VerticalAlignment="Center"/>
                    </Border>
                </ControlTemplate>
            </Setter.Value>
        </Setter>
    </Style>
</ResourceDictionary>

   위의 예시에서 Style은 CustomControl1 컨트롤에 대한 기본 스타일을 정의합니다. 
   이 스타일에는 ControlTemplate이 포함되어 있으며, TextBlock을 이용해 컨트롤의 UI를 정의합니다. 
   스타일은 DefaultStyleKey에 의해 자동으로 Custom Control에 적용됩니다
